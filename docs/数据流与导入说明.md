# 数据流与导入说明

> 说明前端导入的题目如何落库、题目内容的数据形态，以及 19 张业务表的结构与协作关系。

## 1. 前端导入会保存到数据库吗

**会，一定持久化到 MySQL**（非内存/缓存）。关闭重启不丢失。

- **单个新增**：`POST /api/app/admin/questions`
  → `QuestionServiceImpl.addQuestion()`（`@Transactional`）
  → 写主表 `et_question` + `et_question_2_point`（知识点）+ `et_question_2_answer_stage`（答题阶段）。
- **批量导入（Excel）**：`POST /api/app/admin/questions/import/{fieldId}`
  → `QuestionServiceImpl.uploadQuestions()`（POI 逐行解析）
  → 每行调一次 `addQuestion()` 落库。**任何一行数据非法则整批回滚**。

## 2. 题目内容的数据形态（重点）

`et_question.content` 存的是 **XML 字符串**，不是纯文本：

- 写入：前端提交 `questionContent` → `util/xml/Object2Xml.toXml()` 序列化为 XML。
- 读取：`util/QuestionAdapter.getStringFromXML()` 解回结构化题干（含选择题的选项表）再渲染。

好处：能存结构化的题干/选项，并规避 XSS。**改动题目读写时务必走这两个工具类，不要直接拼 SQL 文本。**

## 3. Excel 导入规范

批量导入的列名 / 阶段名为硬编码约定，必须精确匹配，否则该行抛“第 N 行有错误”并回滚。模板文件见 `data/*.xlsx`，列名示例：

- 题目；题型类型（如 单选/多选/判断/填空/简答…）
- 答案；选项 A/B/C/D；分值
- 解析；考点；出处/关键点（关键字）；知识点/知识类；出题所在知识类
- 答题人阶段（如：轮岗两周 / 定岗一个月 / 定岗半年）；所属题库/部门

> 具体列名与顺序以 `data/` 下模板及 `ExcelUtil.java` 的解析逻辑为准；改动模板需同步修改解析代码。

## 4. 数据库表结构与关系（19 张）

### 4.1 用户与权限
| 表 | 作用 | 要点 |
| :-- | :-- | :-- |
| `et_user` | 用户 | admin / student；密码 SHA1 摘要 |
| `et_role` | 角色 | `ROLE_ADMIN` / `ROLE_TEACHER` / `ROLE_STUDENT` |
| `et_r_user_role` | 用户-角色关联 | 多对多 |

### 4.2 题库 / 题目（核心）
| 表 | 作用 | 要点 |
| :-- | :-- | :-- |
| `et_field` | 题库（字段/部门） | `field_name` |
| `et_knowledge_point` | 知识点/知识类 | 归属某 field |
| `et_question_type` | 题型 | 1单选…7分析；`subjective` 标识主观题 |
| `et_question` | 题目主表 | `content`=XML、`answer`、`analysis`、`points`、`creator` |
| `et_question_2_point` | 题目∔知识点 | 多对多 |
| `et_question_2_answer_stage` | 题目∔答题阶段 | 多对多 |
| `et_answer_stage` | 答题阶段 | 轮岗两周 / 定岗一个月 / 定岗半年 |
| `et_reference` | 法规/出处 | 题目出处引用 |
| `et_comment` | 题目评论 | 学员/教师对题目的讨论 |

### 4.3 试卷 / 组卷
| 表 | 作用 | 要点 |
| :-- | :-- | :-- |
| `et_exam_paper` | 试卷 | `content`=试卷 XML |
| `et_practice_paper` | 练习卷 | 随机/按点组卷 |
| `et_group` | 分组 | 组卷组织 |

### 4.4 答题 / 考试记录
| 表 | 作用 | 要点 |
| :-- | :-- | :-- |
| `et_user_exam_history` | 考试历史 | 一次交卷一条（得分、是否通过） |
| `et_user_question_history_t` | 答题明细 | 一道题一条（对/错、作答、耗时） |

### 4.5 其它
| 表 | 作用 |
| :-- | :-- |
| `et_news` | 新闻/公告 |
| `t_c3p0` | 遗留连接池辅助表，**业务无意义，可忽略** |

## 5. 关键数据流

```
题库：et_field ├─ et_knowledge_point ─┐
      et_question_type               ├─ et_question(et_question_2_point /
            └──────── pace + exam     │       et_question_2_answer_stage)
      组卷：et_exam_paper/practice_paper ─▶ et_user_exam_history
      答题：et_user_question_history_t       （一次交卷 + 每道题明细）
      权限：et_user + et_role + et_r_user_role
```

一句话：**题目 = 主表 + 知识点关联 + 答题阶段关联；考试/练习结果 = 历史表 + 明细表；组卷 = 试卷/练习卷。**

## 6. 给导入基建的建议

- `et_question` 现有初始为空（`docs/sql/examxx.sql` 只含基础资源数据），**题库数据需在系统内录入或按上面列名导入**。
- 批量导入前建议先在 `data/` 模板里填数据试导一次，确认列名匹配。
