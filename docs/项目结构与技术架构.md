# 项目结构与技术架构规范

> 交接入口文档。本文描述本仓库整体结构、技术架构与关键约定。
> 配套文档：`数据流与导入说明.md`、`git-workflow.md`、`production-deployment.md`、`spring-boot-migration-baseline.md`、`spring-boot3-migration-plan.md`。

## 1. 项目定位

企业内部**电力题库 + 在线考试**系统（原资深 SSM/SpringMVC + JSP + WAR 工程，已重构迁移）。

当前形态：**Spring Boot 3 单体 API + React 单页应用，二者打成单个可执行 JAR 部署**。

## 2. 技术栈

| 层次 | 选型 | 说明 |
| :-- | :-- | :-- |
| JDK | 17 | `java.version=17` |
| 构建 | Maven | `spring-boot-starter-parent 3.3.5`，`packaging=jar` |
| Web | spring-boot-starter-web | 内嵌 Tomcat |
| 安全 | spring-boot-starter-security | Spring Security 6 + Filter chain，Session 登录 |
| ORM | mybatis-spring-boot-starter 3.0.4 | Mapper XML 位于 `resources/com/extr/persistence/` |
| 数据库 | MySQL 8（`com.mysql.cj.jdbc.Driver`） | 生产/运行库 |
| 测试库 | H2（MODE=MySQL，内存） | 集成测试专用 |
| 前端 | React 18 + TS + Vite | `frontend/` |
| 序列化 | XStream 1.4.20（需 Java17 add-opens） | 题目/试卷内容 XML |
| Excel | Apache POI 5.2.5 | 题库批量导入 |
| 解析 | jsoup | HTML 内容清洗 |
| 缓存 | spring cache（SimpleCacheManager） | ehcache 配置遗留未启用 |

依赖细节见 `pom.xml`。

## 4. 请求架构（数据流）

```
React SPA ──HTTP /api/app/**──▶ AppApiController(@RequestMapping("/api/app"))
        ◀── JSON ──  ├─▶ Service(@Transactional) ─▶ MyBatis Mapper ─▶ MySQL(et_*)
       SPA /app      └─▶ SecurityFilterChain ─ Session 验证角色
```

- 认证：Spring Security 6，`LegacyAuthenticationProvider` 校验用户名/密码；
- 授权：`/api/app/admin/**`=ROLE_ADMIN，`/api/app/student/**`=ROLE_STUDENT；
- 前端会话：`IF_REQUIRED`（Cookie/Session），登录后 `auth/me` 取当前用户；
- SPA 托管：`/app`、`/app/**` forward 到 `static/resources/app/index.html`；
- 文件：`/files/**` 映射到 `examxx.upload-dir`。

## 5. 关键约定与注意点

1. **JDK 必须为 17**；Spring Boot 3 不再兼容 javax/旧 JVM。
2. **XStream 需 `--add-opens java.base/java.util=ALL-UNNAMED`**（及 `java.lang`），并在 `util/xml/Object2Xml.java` 里开放 `com.extr.**` 类型白名单；否则启动/序列化报 SecurityException。
3. **题目/试卷的 `content` 存 XML 字符串**，读写经 `util/xml/Object2Xml.java` 与 `util/QuestionAdapter.java`，勿直接当纯文本处理。
4. **批量导入 Excel 列名/阶段名有硬编码约定**，详见《数据流与导入说明.md》。
5. **h2 不支持嵌套 `RUNSCRIPT`**，集成测试直接加载 `legacy-schema.sql`+`legacy-seed.sql`（或 `h2/data.sql`）。
6. **MyBatis 分页拦截器** `util/MyInterceptor.java` 的 `prepare` 签名已适配 MyBatis 3.5（`Connection, Integer`），改动时勿退回旧签名。
7. **前端产物路径已统一为 `static/resources/app`**（旧 `src/main/webapp/resources/app` 已删除）；新增页面请改 `vite.config.ts` 的 `outDir` 与 `base`。
8. **上传目录**默认 `./uploads`，可用 `EXAMXX_UPLOAD_DIR` 覆盖。
9. **端口/库可经环境变量覆盖**：`EXAMXX_PORT`、`EXAMXX_DB_URL`、`EXAMXX_DB_PASSWORD`、`EXAMXX_UPLOAD_DIR`。

## 6. 构建与验证

```bash
# 前端内嵌产物（改动前端后重新生成）
cd frontend && npm run build:embedded && cd ..
# 后端打包
mvn clean package
# 集成测试（H2，无需 MySQL）
mvn -Dtest=AppApiIntegrationTest test
# 端到端运行（连 MySQL）
java --add-opens java.base/java.util=ALL-UNNAMED \
     --add-opens java.base/java.lang=ALL-UNNAMED \
     -DEXAMXX_DB_PASSWORD='密码' -jar target/examxx-0.0.1-SNAPSHOT.jar
```

验证通过标准：`AppApiIntegrationTest` 全部通过 + `mvn clean package` BUILD SUCCESS + `java -jar` 后 `/app/login` 返回 200。
